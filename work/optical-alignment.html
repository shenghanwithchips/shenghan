optical-alignment.skill

An agent skill for layouts that measure correctly but still look wrong — numeric alignment as the baseline, then small optical nudges that match what the eye perceives.

Open

The problem

Auto-layout, grids, and equal padding often produce interfaces that are symmetric on paper but feel pulled left, heavy at the top, or uneven beside real type and icons. Agents and designers default to “align everything equally,” which does not fix glyph shape, punctuation, visual mass, or misleading bounding boxes.

Core principle

Numeric alignment is the starting measurement, not the final decision. The skill teaches agents to establish the mechanical baseline first, diagnose why perceived balance fails, apply the smallest useful nudge on the axis that matters, and encode the result as a token or a documented one-off.

What the skill covers

  • Headlines, display type, hanging punctuation, and optical margins
  • Button padding, cards, baseline-aware spacing, and icon centering
  • Figma/CSS handoff — wrappers, transforms, and visual-only offsets without shrinking hit areas
  • A review rubric and structured output: baseline → symptom → cause → nudge → implementation → validation

Workflow

Seven steps: measure the grid and metrics; inspect at actual size; name the visual cause; nudge margin, padding, or transform; compare in context beside neighbors; encode repeating patterns; validate in the real browser with responsive states, localization, and focus rings.

Guardrails

No invented universal pixel constants, no judging from CSS alone without rendering, no shrinking touch targets for aesthetics, and no over-tuning dynamic body copy — prioritize stable hero copy, marketing blocks, and reusable UI primitives.
